# 兩岸翻譯與用語對照規範

本文件旨在規範本專案中繁體中文（台灣）與簡體中文（中國大陸）語系檔案之間的翻譯與同步標準。

## 核心原則

1. **僅轉換兩岸用語差異**
   * 翻譯時僅能針對兩岸慣用的詞彙、語氣或拼寫進行對應轉換（例如：資訊 $\rightarrow$ 信息、網路 $\rightarrow$ 网络、販售 $\rightarrow$ 贩卖）。
   * 繁簡字體轉換應符合各區域的閱讀習慣。

2. **嚴禁調整或移除核心內文**
   * **禁止擅自調整、刪改或移除**任何實質性內容，包含但不限於論述邏輯、科學數據、引用文獻等。
   * **禁止變更地理或政治實體名稱**：專案中的國名、地區名（如「台灣」、「臺灣」、「Taiwan」、「中華民國」等）皆為客觀研究論述之背景，**翻譯時必須完整保留，嚴禁移除或改寫**。

3. **格式與架構保持一致**
   * 翻譯後的簡體中文（`zh_CN`）檔案在資料結構（如陣列順序、物件欄位、Key 值名稱等）上必須與繁體中文（`zh_TW`）保持 100% 絕對一致，僅能替換字串內容。

## 執行與驗證

* **同步流程**：每次修改 `zh_TW` 的語彙檔案後，必須同步至 `zh_CN` 並完成繁簡用語轉換。
* **Git 審查**：提交 Pull Request 之前，請務必比對 `zh_TW` 與 `zh_CN` 的 diff，確認無任何未授權的內文刪改或漏譯。
