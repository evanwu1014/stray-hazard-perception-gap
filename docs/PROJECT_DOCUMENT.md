## 語意本地化與用語對照規範 (i18n)

本專案導入了簡潔的國際化（i18n）切換機制，並在設計上要求不同語系必須遵循其在地化的習慣用語，以達最佳的資訊溝通與學術準確性。

### 核心設計規範
1. **台灣繁體 (zh_TW)**：使用台灣本土的生態、社會與動保習慣用語。
2. **中國簡體 (zh_CN)**：使用中國大陸本土的生態、社會與流浪動物管理用語。
3. **無政治標籤**：畫面上僅以「繁」/「简」或「繁體中文」/「简体中文」提供切換，不特別標明或明示國籍或地區名稱。
4. **檔案架構**：所有翻譯文本與數據必須分別存放在 [zh_TW](../src/data/locales/zh_TW) 與 [zh_CN](../src/data/locales/zh_CN) 資料夾中。
