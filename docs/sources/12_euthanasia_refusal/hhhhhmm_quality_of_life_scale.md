# 寵物生活品質評估量表 HHHHHMM Scale (5H2M)

本文件收錄由獸醫腫瘤學家 Alice Villalobos 博士於 2004 年提出、並廣泛應用於獸醫安寧照護（Pawspice）與生命末期決策的「HHHHHMM 生活品質評估量表」，用以支持對已陷入末期病痛動物進行人道安樂死決策之客觀福利基準。

## 2. HHHHHMM 七項量化評估指標
量表針對動物的生理與心理健康狀況分為七個維度，每個維度給予 **0 至 10 分**（10 分代表最理想狀態，0 分代表最差狀態）：

| 指標縮寫 | 指標名稱 (中文/英文) | 評估重點與客觀標準 |
| :---: | :--- | :--- |
| **H** | **疼痛控制**<br>(Hurt) | - 動物的疼痛是否得到妥善管理？呼吸是否順暢？<br>- **特別注意**：呼吸困難（Dyspnea）的痛苦高於一切，若動物無法順暢呼吸，此項應給予極低分。是否需要氧氣治療？ |
| **H** | **飢餓感與食慾**<br>(Hunger) | - 動物是否能主動進食？食欲如何？<br>- 是否需要靠人工灌食、誘食，或必須裝設餵食管（Feeding Tube）才能維持基本熱量？ |
| **H** | **水分攝取**<br>(Hydration) | - 動物是否脫水？皮膚彈性是否變差？<br>- 是否能自主飲水？是否需要每日施打皮下點滴（Subcutaneous Fluids）來維持體內水分平衡？ |
| **H** | **衛生狀況**<br>(Hygiene) | - 動物是否能保持自身清潔（特別是在排泄之後）？是否會沾黏糞尿？<br>- 是否因長期臥床而產生壓瘡／褥瘡（Pressure Sores）？傷口是否得到妥善包紮與護理？ |
| **H** | **快樂感**<br>(Happiness) | - 動物是否對家庭成員、遊戲、玩具或周遭環境展現好奇心與正面互動？<br>- 是否表現出抑鬱、無精打采、焦慮、孤立或恐懼？是否仍有尊嚴？ |
| **M** | **行動能力**<br>(Mobility) | - 動物是否能自主站立、行走與排泄？<br>- 是否需要輔具（如輪椅、推車、毛巾提帶）或人類完全協助才能移動？是否頻繁抽搐、癲癇或因關節炎劇痛無法起身？ |
| **M** | **好日子多於壞日子**<br>(More good days...) | - 當壞日子（動物整天痛苦、喘氣、不適、眼神呆滯）的數量多於好日子（能進食、互動、情緒平穩）時。<br>- 這是衡量生命尾聲最重要的綜合指標。當壞日子連續占主導，即代表生活品質已崩潰。 |

## 3. 分數解讀與決策指引
- **總分計算**：將上述七項指標的分數相加，總分為 **70 分**。
- **合格分數（35 分）**：
  - **35 分以上**：通常代表動物的生活品質尚可接受，飼主與獸醫可繼續進行積極的安寧療護（維持生命舒適度、止痛）。
  - **低於 35 分**：代表動物的生理與心理福利已受到嚴重折磨，生活品質已經崩塌。此時，為了動物福利，**人道安樂死（Euthanasia）應被視為終止痛苦的慈悲選項**，而非「放棄生命」。

---

## 4. 理論意義：對抗善意悖論
本量表提供了一套客觀的、去情感化的科學評量工具。在動保實務中，許多飼主或機構打著「不放棄治療」、「堅持生命權」的旗號，反覆進行無效醫療或拒絕安樂死，這在福利計量上實則是讓已無康復希望的個體承受長達數週甚至數月的極端痛苦。透過 HHHHHMM 量表的量化計分，能幫助照顧者排除內疚與罪惡感，做出符合動物福利本質的終局決定。
