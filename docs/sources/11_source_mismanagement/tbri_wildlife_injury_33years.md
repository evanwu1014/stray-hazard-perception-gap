# 農業部生物多樣性研究所 33 年野生動物救傷數據分析（遊蕩犬貓攻擊事件）

本文件記錄並彙整農業部生物多樣性研究所（以下簡稱「生多所」，前身為特有生物研究保育中心）野生動物急救站，針對長期收治野生動物之數據分析，用以支持流浪動物源頭失管、放養對野生動物掠食危害之客觀計量。

## 2. 核心統計數據與發現

### 2.1 零撲殺政策上路前後之增幅對照
研究以 **2017 年**實施公立收容所「零撲殺（停止人道撲殺）」政策為分水嶺，對照「政策實施前（1993-2017 年）」與「政策實施後（2018-2025 年）」野生動物遭遊蕩犬貓攻擊並送至急救站的案例數量：
- **整體野生動物受襲案例**：零撲殺政策實施後，遭遊蕩犬貓攻擊的救傷個體數量較實施前增加了 **1.84 倍**。
- **穿山甲受襲案例**：穿山甲成為近年來遊蕩犬攻擊的「最大苦主」，其因犬隻攻擊而送傷的案例增幅高達 **3.56 倍**。

### 2.2 野生動物遭攻擊後之高死亡率
數據顯示，遭遊蕩犬貓襲擊的野生動物，即使成功送至急救站，其預後通常極差，野放率偏低：
- **遭犬隻攻擊**：送醫後死亡率（包含傷重不治與因無法治癒而執行人道安樂死）**超過五成（53.18%）**。
- **遭貓隻攻擊**：送醫後死亡率更**高達七成以上（71.6%）**。這主要是因為貓隻爪子帶有大量細菌，極易在野生動物身上造成微小卻致命的深層感染與敗血症。

### 2.3 受害物種分析
- **穿山甲**：過去穿山甲受傷的主因是人類非法放置的「獸鋏（捕獸夾）」；近年因法令嚴禁及宣導，獸鋏傷比例下降，但取而代之的是「犬隻攻擊」成為最大致殘與死亡主因。傷口多集中於尾部，常導致斷尾、尾部鱗片剝落或嚴重感染，使其喪失攀爬、育幼與挖掘避難的能力。
- **石虎**：石虎的生存範圍與遊蕩犬共域比例高達 90%。研究指出，石虎的死亡原因中，「犬殺（遭犬隻群體圍攻致死）」佔有極高比例。若犬隻威脅不予控制，研究警示石虎族群在百年內的滅絕風險將顯著攀升。
- **山羌與食蛇龜**：山羌在遭遇犬隻追咬時極易因過度緊迫（橫紋肌溶解症）而死亡；食蛇龜則常被犬隻咬碎龜殼，導致致命創傷。

## 3. 理論與政策啟示

1. **源頭治理的迫切性**：
   野生動物急救站的數據直接證實了遊蕩犬貓在野外維持高密度對原生物種造成的毀滅性威脅。這些遊蕩犬貓的核心來源包含「飼主棄養」與「縱放未絕育家犬繁殖」。若未能從源頭（晶片強制登記、絕育、限制自由放養）進行管制，下游的救傷與收容都將無法應付持續擴大的生態損害。
2. **餵養行為的生態外溢**：
   研究指出，在生態敏感區（如石虎、穿山甲棲地周邊）進行流浪動物投餵，會吸引並維持遊蕩犬貓的高密度群聚，直接加劇了犬貓對原生野生動物的獵殺壓力。因此，限制餵食是保育野生動物的必要手段之一。
